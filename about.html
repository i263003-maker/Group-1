Website Configuration

This site is a static HTML/CSS/JavaScript application. Key components:

  • HTML5 markup with responsive containers.
  • Styling in assets/css/styles.css (orange theme, panels, layout).
  • Vanilla JavaScript modules in assets/js (state.js, pages.js, chrome.js, app.js) for routing, search, Steam integration, and UI interactions.
  • Game data in assets/js/games-data.js and site metadata in about.json.
  • All assets (images, thumbnails, icons) live under assets/.

The build process is trivial: open index.html in a browser. For local development you can serve the folder with any static server, e.g., python -m http.server.
